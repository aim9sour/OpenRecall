# OpenRecall 1.0.0

The first stable OpenRecall release is a local-only, accessible spaced-
repetition app for Windows, Chrome, and NVDA.

## Download

Download `OpenRecall-v1.0.0-windows-x64.zip`, extract the entire archive, then
double-click:

- `OpenRecall.cmd` for normal data in
  `%LOCALAPPDATA%\OpenRecall-nodejs\Data`.
- `OpenRecall-Portable.cmd` for portable data in `Data` beside the launcher.

The ZIP contains its own verified Node.js 24.18.0 runtime. No Node, pnpm,
installer, administrator access, account, or network connection is required.

## Highlights

- English and Arabic UI with persistent language selection and RTL/LTR.
- Screen-reader-first review focus and concise live announcements.
- FSRS-6 scheduling, readable rating intervals, and a continuous due queue.
- Smart presentation variants sharing one learning-item schedule.
- Section management, import duplicate preview, statistics, optimizer controls,
  SQLite backup, and validated restore.

See `OpenRecall-v1.0.0-windows-x64.zip.sha256` for the SHA-256 checksum. GitHub
also publishes a provenance attestation for the ZIP; verify it with:

```bash
gh attestation verify OpenRecall-v1.0.0-windows-x64.zip -R aim9sour/OpenRecall
```

# OpenRecall 1.0.1

OpenRecall 1.0.1 is a stable Windows correctness release for the local-only,
accessible spaced-repetition application.

## Download

Download `OpenRecall-v1.0.1-windows-x64.zip`, extract the entire archive, then
double-click:

- `OpenRecall.cmd` for normal data in
  `%LOCALAPPDATA%\OpenRecall-nodejs\Data`.
- `OpenRecall-Portable.cmd` for portable data in `Data` beside the launcher.

Both launchers wait for the loopback server health check before opening the
Windows default browser. The ZIP contains its verified Node.js 24.18.0 runtime;
no separate Node, pnpm, installer, administrator access, or account is needed.

## Fixes

- Dashboard due counts and next-due times now come from the actual scheduler
  state and refresh as time advances.
- A review with due cards opens on the first question without briefly claiming
  that no cards are available.
- Windows opens the configured default browser only after the server is ready.
- The old browser-cache update prompt is removed. A browser profile that used
  1.0.0 receives a same-URL compatibility worker that deletes old caches and
  unregisters itself once. New profiles do not register a service worker.

## Data safety

This release has no database migration. Normal data remains under Local App
Data; portable data remains in the extracted folder's `Data` directory. Keep
that portable `Data` folder when replacing application files, and create a
SQLite backup from Settings before moving or replacing data.

See `OpenRecall-v1.0.1-windows-x64.zip.sha256` for the SHA-256 checksum. Verify
the GitHub provenance attestation with:

```bash
gh attestation verify OpenRecall-v1.0.1-windows-x64.zip -R aim9sour/OpenRecall
```

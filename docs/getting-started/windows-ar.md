# تشغيل OpenRecall على Windows

OpenRecall تطبيق محلي شخصي. يستمع فقط على `127.0.0.1`، ولا يحتاج إلى حساب
أو خدمة سحابية.

## المتطلبات

- Windows 10 أو 11.
- Node.js 24، على ألا يقل عن 24.18.
- pnpm 11، والإصدار الموصى به هو 11.17.0.
- Google Chrome، ومعه NVDA عند استخدام قارئ الشاشة.

تحقق من النسخ في PowerShell:

```powershell
node --version
pnpm --version
```

## التثبيت والبناء

افتح PowerShell داخل مجلد المستودع ونفّذ:

```powershell
pnpm install --frozen-lockfile
pnpm build
```

لا تقوم سكربتات OpenRecall بتنزيل Node.js أو pnpm، ولا تطلب صلاحيات المسؤول.

## التشغيل

يمكنك التشغيل من جذر المستودع:

```powershell
pnpm start
```

أو انقر نقرًا مزدوجًا على `scripts\start-openrecall.cmd`. يفوض ملف CMD
التشغيل إلى `start-openrecall.ps1`، الذي يتحقق من Node.js 24 وpnpm 11 ثم
يشغّل الأمر نفسه من جذر المستودع.

بعد ظهور `OPENRECALL_READY` افتح Chrome على:

`http://127.0.0.1:3210`

إذا كان OpenRecall يعمل بالفعل، فالمحاولة الثانية تعرض
`OPENRECALL_ALREADY_RUNNING` وتنتهي بنجاح. لا يختار التطبيق منفذًا آخر
مفاجئًا. إذا كان برنامج مختلف يحتل المنفذ فسيظهر الكود
`OPENRECALL_PORT_OCCUPIED`؛ أغلق ذلك البرنامج أو غيّر إعداداته، ثم أعد
تشغيل OpenRecall.

## تثبيت PWA في Chrome

افتح القائمة في Chrome واختر تثبيت OpenRecall، أو استخدم رمز التثبيت في شريط
العنوان. تعمل PWA كنافذة مستقلة. يحتفظ وضع عدم الاتصال بغلاف الواجهة فقط؛
لا يخزن ردود API أو نصوص البطاقات في مخزن المتصفح. عند توفر تحديث سيظهر
زر صريح لتطبيقه، ولن يعيد تحميل جلسة مراجعة نشطة تلقائيًا.

## البيانات والنسخ الاحتياطية

المكان الافتراضي للبيانات هو:

`%LOCALAPPDATA%\OpenRecall-nodejs\Data`

توجد قاعدة البيانات في `openrecall.sqlite3`، والنسخ الاحتياطية SQLite داخل
المجلد `OpenRecall-nodejs\Data\backups`، والسجلات الخالية من محتوى البطاقات
داخل `OpenRecall-nodejs\Data\logs`. استخدم وظائف النسخ والاستعادة داخل
التطبيق، ولا تعدّل ملفات SQLite أثناء عمل الخادم.

## الإيقاف وإعادة التشغيل

ارجع إلى نافذة PowerShell واضغط `Ctrl+C`. انتظر حتى يعود سطر الأوامر؛ عندها
يكون الخادم قد أوقف جلسات SSE والمؤقتات، ونفّذ checkpoint آمنًا، وأغلق قاعدة
البيانات. أعد التشغيل لاحقًا باستخدام `pnpm start` أو
`start-openrecall.cmd`.

## عندما تظهر صفحة تعذر الاتصال بالخادم

1. تأكد أن نافذة الخادم ما زالت مفتوحة.
2. شغّل `scripts\start-openrecall.cmd` من المستودع.
3. انتظر `OPENRECALL_READY` ثم استخدم زر إعادة المحاولة في الصفحة.
4. إن ظهر `OPENRECALL_PORT_OCCUPIED`، تحقق من البرنامج الذي يستخدم المنفذ
   3210؛ لا تحذف قاعدة البيانات ولا مجلد النسخ الاحتياطية.
5. إذا استمر الخطأ، احتفظ بكود التشخيص الظاهر فقط عند طلب المساعدة؛ لا حاجة
   إلى مشاركة بطاقاتك أو ملف SQLite.

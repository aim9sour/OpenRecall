# OpenRecall v1.1.0 Dependency Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrate the reviewed compatible dependency baseline, disposition every open Dependabot PR with evidence, and publish a verified public OpenRecall `v1.1.0` Windows release.

**Architecture:** Work only on `release/v1.1.0` until a protected squash-merge PR is green. Treat the root manifest as the release-version source of truth, keep Node 24 as the runtime/type boundary, explicitly approve native build versions, and let the tag-triggered workflow create and attest release assets. External GitHub state changes happen only after local and PR gates prove the source tree.

**Tech Stack:** Node.js 24.18.0, pnpm 11.17.0, TypeScript 7.0.2, Fastify 5, React 19, Vite 8, SQLite/better-sqlite3, Vitest 4, Playwright 1.62, axe-core, GitHub Actions, GitHub CLI, PowerShell 5.1+.

## Global Constraints

- Follow `docs/superpowers/specs/2026-08-11-v1.1.0-dependency-release-design.md` exactly.
- Runtime and bundled Node remain `24.18.0`; `engines.node` remains `>=24.18.0 <25`; `@types/node` remains `24.13.3`.
- pnpm remains exactly `11.17.0`; every direct non-workspace dependency remains exact.
- Do not weaken optimizer, accessibility, database, supply-chain, or package assertions merely to accept an update.
- Do not touch NVDA or any machine-level screen-reader setting.
- Do not merge or close a bot PR until `main` contains the evidence-backed replacement or an explicit incompatibility is established.
- The main agent makes every source/external-state change; independent agents are read-only reviewers.
